# ПОВЕДЕНИЕ — НАСТРОЙКА СИСТЕМНОГО ПРОМПТА (config\behavior.md)

**Назначение файла (единственное):** текст `SYSTEM`-слоя для локальных моделей Ollama.
**Связанные файлы:** параметры сэмплинга — `config\behavior.json`; применение — `tools\Apply-AgentParams.ps1`.

## Как включить

В `behavior.json` поставить `"systemPrompt": { "enabled": true, "file": "behavior.md" }`,
затем запустить `tools\Apply-AgentParams.ps1 -SystemPrompt`.
Скрипт добавит в модель слой `SYSTEM` с текстом **только между маркерами** ниже.

**Сейчас: ВЫКЛЮЧЕНО (enabled=false).** В Cline это редко нужно — там свой системный промпт.
