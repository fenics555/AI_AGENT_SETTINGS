# Блок для .clinerules / MANIFEST: анти-галлюцинации (можно вставлять как есть)

Задание, которое можно вставить в `D:\AI\.clinerules` (или в `D:\AI\repo\MANIFEST.md`,
или вынести в скилл направления, например `SKILL_anti_hallucination.md`).

Важно: это текстовые правила (влияют на поведение модели через промпт), они **не меняют**
параметры сэмплинга и **не снижают скорость** генерации — в отличие от `temperature`/`num_ctx`.

```
12. АНТИ-ГАЛЛЮЦИНАЦИИ (v1):
   - Запрещено называть факты, которых нет в прочитанных файлах/выводе инструментов.
     Нет источника = нет утверждения. Формат: «данных нет; искал в <файлы/команды>».
   - Каждый факт о проекте сопровождается источником: <путь>:<строка> или команда + её вывод.
   - Запрещены «правдоподобные» номера ГОСТ/ТУ/патентов/пунктов/адресов/имён файлов
     без дословного подтверждения из чтения. Номер без источника = нарушение.
   - Пути и имена проверяются существованием (Test-Path / Select-String / dir),
     запрещено «достраивать» имя по аналогии.
   - Результат команды приводится дословно (ключевая строка целиком), запрещено
     пересказывать «по смыслу» и запрещено придумывать вывод при таймауте: таймаут = «нет результата».
   - Различать три уровня и помечать их явно:
     ФАКТ (есть источник) / ПРЕДПОЛОЖЕНИЕ (гипотеза, требует проверки) / НЕТ ДАННЫХ.
   - Перед выводами о поведении внешнего ПО (Creo, Ollama, python-модуль) обязателен
     probe: версия + фактический вывод команды, а не память о версии.
   - Если вопрос пользователя основан на несуществующей сущности — прямо сказать:
     «такого параметра/файла/ГОСТ не существует» и указать, как проверялось.
```

Комментарий по моделям (для справки, из локальных замеров этой машины):

- Плотные (`gemma4:31b`, `granite4.2:30b`): качество/точность выше, но при окне 200k
  упираются в CPU (2–4 t/s). Для них: окно 8–32k в Cline, либо работать через MoE-модель.
- MoE + MTP (`gemma4:26b`, `nemotron-3.5-lightning:30b`): 26–56 t/s даже при окне 202k.
- `temperature 1.0` (дефолт всех ваших моделей) — главный источник «отсебятины»;
  правило промпта снижает его частично, но `temperature 0.3` через копию `-strict` — сильнее.
