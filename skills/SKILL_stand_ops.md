# ОПЕРАЦИИ СТЕНДА — ЗАПУСК, ОКНО, ГРАБЛИ, РЫЧАГИ (17.10.2026)

## 0. 🔴🔴 НА ЛБУ: КАК ВЫВОДИТЬ ОКНО ПРОГОНА (ОБЯЗАТЕЛЬНО ДО КОНЦА)

> **Владелец: «НАПРИ НА ЛБУ».** Повторять при КАЖДОМ запуске. Пропуск = прогон не запущен.

**В окне ОБЯЗАНО быть ВСЁ это (5 пунктов, §6.1.6):**
```
1. ХОД      — фаза, модель, шаг, лог жив
2. RESULT   — вердикты (COUNT_OK / SKILL_READ / …)
3. ОТВЕТЫ МОДЕЛЕЙ — ФИНАЛЬНЫЙ ОТВЕТ, Ш1..Ш5, ОПРОС МОДЕЛИ  (ЦЕЛИКОМ, не усечённо)
4. ТОКЕНЫ   — tokens=<N> по КАЖДОЙ задаче
5. ВРЕМЯ    — sec=<N> по КАЖДОЙ задаче + СТАРТ → ФАКТ фазы
```
**НЕТ любого пункта = НАРУШЕНИЕ §6.1.6 = работа не принята.**

**ГЛАВНЫЕ ГРАБЛИ ОКНА (все стоили прогонов!):**
| # | грабля | лечение |
|---|---|---|
| 1 | `> файл 2>&1` в команде `start` → окно пустое | прогон в файл + **ОТДЕЛЬНОЕ окно-наблюдатель** |
| 2 | окно агента владелец НЕ видит | запускать окно отдельной командой + `MainWindowHandle -ne 0` + WinAPI, если 0 |
| 3 | **`-Exclude` + `-Filter` в PS 5.1 = ПУСТО** | фильтровать `Where-Object`, НЕ `-Exclude` |
| 4 | правка скрипта не видна в запущенном окне | **убить процесс окна и запустить заново** |
| 5 | пустой свежий лог (97 б) перебивает полный | фильтр `Length -ge 500` |
| 6 | кириллица в заголовке окна → чёрное окно | заголовок ASCII |

**КОМАНДЫ (копировать как есть):**
```powershell
# 1) ПРОГОН (в файл):
cmd /c start "" cmd /c "powershell -NoProfile -ExecutionPolicy Bypass -File <тест>.ps1 <параметры> > <tmp>\<tag>_out.txt 2>&1"

# 2) ОКНО-НАБЛЮДАТЕЛЬ (владельцу):
cmd /c start "STEND LIVE" powershell -NoProfile -NoExit -ExecutionPolicy Bypass -File D:\AI\AGENT_SETTINGS\tmp\watch_live.ps1 -Tag <tag> -Every 10

# 3) ПРОВЕРКА, что окно ЕСТЬ и ВИДНО:
Add-Type -AssemblyName System.Windows.Forms; Get-Process powershell | Where-Object { $_.MainWindowHandle -ne 0 } | Select Id, MainWindowTitle
```
