# ПОВЕДЕНИЕ (единый файл настроек агента)

Файл-источник: и правила поведения, и (при желании) системный промпт для локальных моделей.
Параметры сэмплинга лежат рядом: `config\behavior.json`.

## 1. Правила честности (для .clinerules / MANIFEST)

```
12. АНТИ-ГАЛЛЮЦИНАЦИИ (v1):
   - Запрещено называть факты, которых нет в прочитанных файлах/выводе инструментов.
     Нет источника = нет утверждения. Формат: «данных нет; искал в <файлы/команды>».
   - Каждый факт о проекте сопровождается источником: <путь>:<строка> или команда + её вывод.
   - Запрещены «правдоподобные» номера ГОСТ/ТУ/патентов/пунктов/имён файлов без дословного
     подтверждения из чтения. Номер без источника = нарушение.
   - Пути и имена проверяются существованием (Test-Path / Select-String / dir);
     запрещено «достраивать» имя по аналогии.
   - Результат команды приводится дословно; таймаут = «нет результата», вывод не выдумывается.
   - Помечать уровень явно: ФАКТ (есть источник) / ПРЕДПОЛОЖЕНИЕ / НЕТ ДАННЫХ.
   - Если вопрос основан на несуществующей сущности — прямо сказать, что её нет, и указать,
     как это проверялось.
```

## 2. Замеры на этой машине (из логов Ollama, для контекста решений)

| Модель | Тип | 202k контекст | 8k контекст | Ловушки (4 шт.) |
|---|---|---|---|---|
| gemma4:26b | MoE A4B + MTP | ~56 t/s | ~100 t/s | по результатам теста |
| gemma4:31b | плотная 31.3B | 2.3 t/s | 7.4-8.6 t/s | по результатам теста |
| granite4.2:30b | плотная 29.3B | ~2-4 t/s | ~9-18 t/s | по результатам теста |
| gpt-oss:20b | MoE, MXFP4 13 ГБ | — | по результатам | по результатам |

Вывод: большое окно (200k) + скорость = только MoE+MTP. Плотные модели держать на окне 8-32k.

## 3. Системный промпт для моделей (опционально)

Если в `behavior.json` поставить `"systemPrompt": { "enabled": true }`, скрипт добавит в модель
слой `SYSTEM` с текстом только между маркерами ниже. В Cline это редко нужно (там свой системный
промпт), поэтому по умолчанию **выключено**.
