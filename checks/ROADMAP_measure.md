## 4. Чего НЕ делать (зафиксировано, чтобы не повторять)

- **Не внедрять «Тензор» (геометрическое среднее с барьером)** — при пороге по честности
  непрерывная шкала становится фикцией, это замаскированный PASS/FAIL.
- **Не строить оси «Смелость»/«Дисциплина»** — они объясняют один и тот же предмет `l5`,
  то есть двойной счёт (ортогональность нарушена).
- **Не лечить поведение кручением `temperature` без данных** — подтверждённой связи
  `temperature` → смелость нет ни в одном прогоне; laguna реагирует на текст правил (Слой 2).
- **Не ставить «стабильность» множителем в общий скор** — прогон на 3 seed стоит ×3 по времени,
  повторяемость токенов ≠ повторяемость поведения.
- **Радар/ASCII-графика** — только представление для человека, не замена вердикту.
