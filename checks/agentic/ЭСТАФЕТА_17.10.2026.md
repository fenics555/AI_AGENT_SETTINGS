### 4.1. ЗАПУСК ДОЛГОГО ПРОГОНА УМИРАЕТ С РОДИТЕЛЕМ
- `Start-Process powershell -NoExit -File run.ps1` из инструмента агента -> **умрёт на 30-й сек**
  (родитель = shell агента, таймаут 30 с).
- **Признак:** сводка есть, `процессов: 0`, окна нет, лог теста оборван.
- **ЛЕЧЕНИЕ:** `Start-Process cmd -ArgumentList @('/c','powershell ... -File run.ps1')`.
  `cmd /c` **отвязывает** от родителя. Записано: `SKILL_think_probe.md` §17.1.
- **Python:** обязателен `flush=True`, иначе файл 0 б до конца.

- Ошибка параметра **не падает сразу** — тихо берёт **дефолт `A,D`** -> прогон мусорный. **Смотреть `rulesets=R_...` в логе!**

```

# Modelfile: FROM <блоб> + TEMPLATE """<chat_template из GGUF>"""
ollama create <модель>-fixed -f Modelfile
```
**ВЫВОД:** «плохое поведение модели» может быть **дефектом её Modelfile**. Сначала проверять
`TEMPLATE`/`RENDERER`, потом винить модель.
