## 7. ДИАГНОСТИКА ФЛАГА (см. `SKILL_think_probe.md` §16)

> Тест 1 проходят все, дальше — по-разному. 🔴 **ФЛАГ ≠ ПРИГОВОР:** «модель виляет» — диагноз для
> **точечной правки**, а не «нельзя починить». Доказано §4: v26→v30 вытянули непрошедшую модель на 5/5
> формулировкой под её слабое место (текст подсказала сама модель, Ш3).

**Развилка — сколько ПЯТЬ диагнозов (не «кто виноват»):**

| Диагноз | Что делать |
|---|---|
| 1. Модель не поняла, что от неё хотят | **точечная правка** (одна формулировка под слабое место) — работает |
| 2. Поняла, но не хватает механизма («не умею / не вижу») | попробовать один замер, может не помочь |
| 3. Знает, не делает, формулировка безразлична (5 правок → то же) | флаг остаётся, тема закрыта |
| 4. Правка под неё ломает других | **ОТКАТ**, тема закрыта |
| 5. Добавление текста делает хуже (слабая падает, эталон держится) | **ОТКАТ**, тема закрыта |

**ТРИ основания отказаться от правки (только они):** перестановка провала · деградация соседей · пять попыток без сдвига.

**Алгоритм:** дословный ответ + trace → проба руками → критерий на известном ответе → Ш3 («что мешает/что менять» = готовая гипотеза правки) → **ОДНА** правка в копию закона → **ОДИН** замер.
Исходы замера: все прошли → принять · флагованная прошла, другая упала → откат · флагованная падает, другие целы → другая формулировка · все упали → откат.
